# PARCIAL 2 - Tienda en Línea

## Descripción

Este proyecto implementa un sistema de gestión de productos para una tienda en línea, demostrando el uso de algoritmos de ordenamiento y búsqueda en datos reales.

## Objetivos

- Implementar **3 algoritmos de ordenamiento** (Merge Sort, Quick Sort, Insertion Sort)
- Ordenar productos por **precio** (ascendente) y **calificación** (descendente)
- Implementar **búsqueda binaria** por ID y **búsqueda lineal** por nombre
- Medir y comparar el rendimiento de los algoritmos
- Analizar los resultados y su relación con la teoría
